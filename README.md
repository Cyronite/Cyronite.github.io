# Prasun Sharma

Personal portfolio with highlights, experience, selected projects, and an interactive wave background.

- https://cyronite.github.io/
- https://prasun-sharma.vercel.app/

Static HTML, CSS, and JavaScript. No build step. Serve this folder with a local HTTP server. GitHub Pages and Vercel deploy from `main`.

The layout adapts to the viewport and uses page arrows when content needs more room. Animation respects reduced-motion preferences and can be paused.
